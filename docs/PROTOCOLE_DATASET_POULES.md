# Protocole dataset poules

Objectif minimal avant un premier entraînement expérimental : 30 captures différentes, idéalement 100 ou plus.

Pour chaque capture :
- encadrer toutes les poules visibles ;
- encadrer les monstres régulièrement confondus comme `not_chicken` ;
- conserver des scènes avec chevauchements, animations, densités et positions différentes ;
- ne pas encadrer le nom, les effets ou le sol avec le monstre.

Le premier modèle ne devra être branché au clic réel qu'après validation sur des captures non utilisées pour l'entraînement.
