# EPIC-02 — Gestion des familiers

## Objectif

Détecter, inspecter, sélectionner et parcourir les familiers visibles.

## User Stories

- [ ] PET-001 — Détecter tous les familiers visibles
- [x] PET-002 — Cliquer sur un familier détecté
- [x] PET-003 — Ouvrir la fiche et cliquer sur Accompagner
- [ ] PET-004 — Parcourir les familiers de haut en bas
- [ ] PET-005 — Détecter le familier actuellement sélectionné
- [ ] PET-006 — Détecter si un familier est déjà accompagné
- [ ] PET-007 — Lire son niveau
- [ ] PET-008 — Lire son nombre d’étoiles
- [ ] PET-009 — Choisir les familiers à entraîner
- [ ] PET-010 — Passer automatiquement au suivant

## Règles métier initiales

- Un familier déjà à 6 étoiles ne doit plus être amélioré.
- Un familier déjà au niveau cible peut être ignoré.
- Le nombre de familiers accompagnés simultanément est limité.
- La fiche du familier doit être ouverte avant de rechercher le bouton
  Accompagner.
