# Diagnostic

Après clic sur « Détecter les poules », le statut doit toujours changer.

- `Template « chicken » introuvable` : créer le template dans l'écran Templates.
- `Fenêtre NosTale introuvable` : ouvrir le client et vérifier son titre.
- `0 poule détectée` : baisser progressivement le seuil (0,85 -> 0,80 -> 0,75) ou recréer un template plus caractéristique.
- `Erreur pendant la détection...` : transmettre le message complet.
