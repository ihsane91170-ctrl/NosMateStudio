# Lecture du diagnostic

Après « Détecter les poules » :

- score proche du seuil (ex. 0,76 pour 0,80) : baisser légèrement le seuil ;
- score moyen (0,45 à 0,65) : recréer un template plus petit ou ajouter plusieurs poses ;
- score faible (<0,30) : le template ne correspond probablement pas à l'apparence visible.

Le rectangle affiché quand le score est sous le seuil indique la zone qui ressemble le plus au template. Il sert uniquement au diagnostic et n'active pas le bouton de clic réel.
