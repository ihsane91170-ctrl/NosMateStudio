# Vision produit

## Problème

La préparation d'une session d'entraînement NosMate demande une succession d'actions répétitives :
capture, téléportation, invocation et affectation de trois familiers.

## Proposition de valeur

NosMate Studio réduit ces manipulations grâce à une application Windows :

- configurable ;
- observable grâce à un journal ;
- sécurisée par un mode simulation et un arrêt d'urgence ;
- robuste grâce à la validation des étapes ;
- évolutive grâce à une architecture modulaire.

## Utilisateur principal

Joueur connaissant le workflow NosMate et souhaitant automatiser la préparation d'une session.

## Principe produit

Le logiciel ne doit pas seulement cliquer. Il doit :

1. observer l'état du jeu ;
2. décider de l'action suivante ;
3. exécuter l'action ;
4. vérifier le résultat ;
5. s'arrêter proprement en cas d'anomalie.
