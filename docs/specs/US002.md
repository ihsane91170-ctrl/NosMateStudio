# US002 — Configurer les raccourcis

## Objectif

Permettre de configurer les touches utilisées par les futures automatisations.

## Actions configurables

- Accès au stockage des familiers.
- Accès à la zone d'XP.
- Invocation du Protomonstre faible.
- Invocation du Protomonstre.
- Invocation du Protomonstre fort.

## Touches autorisées

`1`, `2`, `3`, `4`, `5`, `Q`, `W`, `E`, `R`, `T`.

## Contraintes

- Une touche par action.
- Aucun doublon.
- Les lettres sont normalisées en majuscules.
- La configuration locale est sauvegardée hors Git.
- L'interface graphique sera traitée dans une PR suivante.
