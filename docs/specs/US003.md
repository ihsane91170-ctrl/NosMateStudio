# US003 — Calibrer les éléments de l'interface NosTale

## Objectif

Permettre à l'utilisateur d'enregistrer la position des éléments nécessaires
à l'affectation des trois familiers.

## Éléments

- Icône du familier 1.
- Icône du familier 2.
- Icône du familier 3.
- Bouton Accompagner.
- Protomonstre faible.
- Protomonstre.
- Protomonstre fort.

## Fonctionnement

1. L'utilisateur clique sur `Calibrer`.
2. Il place la souris sur l'élément dans NosTale.
3. Un compte à rebours de trois secondes s'exécute.
4. La position est enregistrée relativement à la fenêtre NosTale.

## Contraintes

- Le client NosTale doit être détecté.
- La souris doit se trouver dans la fenêtre.
- La configuration est sauvegardée dans `calibration.local.json`.
- Le fichier local n'est pas versionné.
