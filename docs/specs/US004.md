# US004 — Workflow Engine

## Objectif

Fournir un moteur générique capable d'exécuter une suite d'étapes indépendantes.

## Critères d'acceptation

- Les étapes sont exécutées dans l'ordre.
- Le moteur expose un état explicite.
- Une étape en échec interrompt le workflow.
- Une exception est convertie en état `ERROR`.
- Le contexte permet de partager des données entre étapes.
- Le moteur ne dépend ni de PySide6, ni de PyAutoGUI, ni de NosTale.
- Les événements principaux sont exposés via un callback neutre.
